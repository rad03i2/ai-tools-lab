# Collaboration and Co-authoring

This project welcomes collaborative contributions and records shared authorship explicitly when more than one person contributes to a commit.

## Recommended workflow

1. Work on a focused feature branch.
2. Keep the change small enough to review clearly.
3. When a commit contains substantive work from another contributor, add a correctly formatted `Co-authored-by:` trailer after a blank line in the commit message.
4. Use an email address associated with the contributor's GitHub account so GitHub can link the contribution correctly.
5. Open a pull request and merge the change into the default branch after verification.
6. Preserve the co-author trailer when choosing or editing the final merge message.
