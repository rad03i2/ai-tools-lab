# AI Tools Lab

A practical collection of small AI helper tools written for learning, prototyping, and daily developer productivity.

## What is inside

- Prompt template cleaner
- Simple text summarizer based on extractive scoring
- Local dataset label helper
- Browser prompt playground
- Example task definitions in JSON

## Tech stack

`Python` · `JavaScript` · `JSON` · `CLI` · `Browser`

## Run

```bash
python src/prompt_tools.py examples/tasks.json
```

Open `web/prompt-playground.html` in a browser for the front-end demo.

## Project goal

This repository is intentionally small, readable, and useful. It shows how AI-related tooling can be organized without requiring paid APIs or external services.
